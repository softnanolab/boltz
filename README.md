## Introduction

This branch is a fork from the last Boltz-1 commit and is now being used to retrain the Boltz-1 model. 

## Installation
Install boltz with PyPI (recommended):

```
pip install boltz -U
```

or directly from GitHub for daily updates:

```
uv venv
source .venv/bin/activate
pip install -e .
```
